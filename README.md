# 🌊 AquaPark Management & Booking System

A full-stack web application for water park management, featuring user registration, ticket booking, food menu browsing, and an admin control panel.

---

## 🛠️ Tech Stack

- **Backend:** Python 3, FastAPI, SQLAlchemy, Pydantic, SQLite
- **Frontend:** JavaScript, Vue.js 3, Axios, HTML5/CSS3
- **Security & Integration:** CORS Middleware, REST API

---

## ✨ Features

- 👤 **User Management:** Registration, login, profile view, and wallet balance management.
- 🎟️ **Ticket System:** Browse available tickets and purchase them with automatic wallet deduction.
- 🍔 **Food Ordering:** Browse food items and buy directly from the app.
- 🛡️ **Admin Panel:** Create tickets, manage food inventory, and assign administrative roles.
